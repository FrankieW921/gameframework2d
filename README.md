FRANKLIN WAMSHER'S ATTEMPT AT A 2D MECHA GAME!!!!!!

Controls:
WASD - Move
Left Click - Click a button, shoot, spawn tiles in the Editor
Keys 1-4 - Change Parts
    (additionally to change parts, click the buttons when they appear on the right side of the screen when touching the garage)
Keys 5-9 - Spawn Interactables in the Editor
C, V, B, N, M, X - Spawn Enemies in the Editor


Features:
Enemies! 5 enemies and a boss to fight! Some shoot, some don't, all of them want to and CAN hurt you.
Interactables! A healing zone, the garage, speed gel, an invincibility star, and an (unfinished) teleporter!
Parts! Pickup different parts and change your character at the garage! Each part has different attributes:
    Heads: Fire rate
    Arms: Projectile Fired
    Torsos: I-Frames
    Legs: Movement Speed

All audio files present in class are not here on Github however the game is fully working without them.
